## 108.1 Group Theory

### Theorem 108.1 (Lagrange's Theorem)
If $G$ is a finite group and $H$ is a subgroup of $G$, then $|H|$ divides $|G|$.

**Proof:**
Let $H \leq G$. The left cosets $gH = \{gh : h \in H\}$ partition $G$. All cosets have the same size as $H$ (by multiplication by $g$, which is a bijection). Thus $|G| = [G:H]|H|$, where $[G:H]$ is the number of cosets.

### Theorem 108.2 (Cauchy's Theorem)
Let $G$ be a finite group and $p$ a prime dividing $|G|$. Then $G$ contains an element of order $p$.

**Proof:**
By Cauchy's theorem for abelian groups first (using Sylow theory), then generalize using the class equation or Sylow theorems. For $p$ dividing $|G|$, a Sylow $p$-subgroup exists and has order $p^k$ for $k \geq 1$. By induction on the order, this subgroup has an element of order $p$.

## 108.2 Ring Theory

### Theorem 108.3 (Fundamental Theorem of Arithmetic)
Every integer $n > 1$ can be uniquely written as a product of primes, up to ordering of factors.

**Proof:**
Existence: By induction. If $n$ is prime, done. If composite, $n = ab$ with $1 < a,b < n$. By induction, $a$ and $b$ have prime factorizations.
Uniqueness: Suppose $n = p_1 \dots p_k = q_1 \dots q_m$ with primes. If $p_1$ does not divide any $q_j$, then $\gcd(n,p_1) = p_1$ and $\gcd(n,q_1) < p_1$ (since $q_1 \nmid p_1$ and vice versa). By Euclid's lemma (prime divides product implies divides factor), $p_1$ must divide some $q_j$, contradiction. Thus all primes match.

### Theorem 108.4 (Fundamental Theorem of Arithmetic extension)
Every ideal in a unique factorization domain (UFD) is principal iff the ring is a PID.

**Proof:**
In a UFD, irreducible elements are prime. Every non-zero non-unit factors uniquely into irreducibles. An ideal $I$ is principal iff generated by a single element. In a PID, every ideal is principal, so factorization is unique.

## 108.3 Field Theory

### Theorem 108.5 (Galois Theory Basics)
Let $E/F$ be a finite Galois extension. The fundamental theorem states there is a one-to-one correspondence between subgroups of $\text{Gal}(E/F)$ and intermediate fields $F \subseteq L \subseteq E$, reversing inclusion.

**Proof:**
For $H \leq \text{Gal}(E/F)$, define $E^H = \{x \in E : \sigma(x) = x \forall \sigma \in H\}$. This is an intermediate field. For $F \subseteq L \subseteq E$, define $H = \text{Gal}(E/L)$. The Galois connection is inclusion-reversing and bijective due to the Galois condition (normal and separable extension).

### Theorem 108.6 (Artin's Fundamentel Theorem)
Let $K$ be a finite extension of $F$ generated by a set of elements $S$, i.e., $K = F(S)$. Then $\text{Gal}(K/F)$ is generated by the set of automorphisms that fix each element of $S$ individually.

**Proof:**
For each $s \in S$, let $H_s = \{\sigma : \sigma(s) = s\}$. Then $\text{Gal}(K/F) = \langle H_s : s \in S \rangle$. This follows from the fact that any $F$-automorphism is determined by its action on generators, and the group generated by fixing each $s$ contains all $F$-automorphisms.


## 108.1: Galois Theory Extensions

**Theorem 108.1.1** (Primitive Element Theorem)
Let $L/K$ be a finite separable extension. Then there exists $\alpha \in L$ such that $L = K(\alpha)$.

*Proof*: Let $\alpha_1, \dots, \alpha_n$ be a basis of $L/K$. For any $k \in \mathbb{Z}$, consider $\alpha = \alpha_1 + k\alpha_2 + \dots + k^{n-1}\alpha_n$. For $k_1 \neq k_2$, $\alpha$ generates $L$ because the degree of $K(\alpha)/K$ is $n$. By the Pigeonhole Principle, for sufficiently large $k$, $\alpha$ must have degree $n$.

**Theorem 108.1.2** (Galois Correspondence)
There is a one-to-one correspondence between subgroups of $\text{Gal}(L/K)$ and intermediate fields $K \subseteq E \subseteq L$, given by $E \mapsto \text{Gal}(L/E)$ and $H \mapsto L^H$.

*Proof*: Let $E = L^H$. Then $[L:E] = |H|$ by the First Isomorphism Theorem. The correspondence is inclusion-reversing and preserves fixed fields.

**Theorem 108.1.3** (Primitive Element Theorem for Finite Extensions)
Let $L/K$ be a finite extension. Then $L = K(\alpha_1, \dots, \alpha_n)$.

*Proof*: This is the Primitive Element Theorem, which states that any finite separable extension is simple. For non-separable extensions, we need additional conditions.

## 108.2: Ring Theory

**Theorem 108.2.1** (Artin-Wedderburn Theorem)
A ring $R$ is semisimple if and only if $R \cong M_{n_1}(D_1) \times \dots \times M_{n_k}(D_k)$ where each $D_i$ is a division ring.

*Proof*: This is a structure theorem for semisimple rings. The proof uses the Jacobson density theorem and the double centralizer property.

**Theorem 108.2.2** (Prime Spectrum Structure)
For a commutative ring $R$, the prime spectrum $\text{Spec}(R)$ is a compact Hausdorff space under the Zariski topology.

*Proof*: Open sets in $\text{Spec}(R)$ are of the form $D(f) = \{\mathfrak{p} \in \text{Spec}(R) \mid f \notin \mathfrak{p}\}$. These form a basis for the topology.

## 108.3: Module Theory

**Theorem 108.3.1** (Schur's Lemma)
Let $M, N$ be irreducible modules over a ring $R$. Then $\text{Hom}_R(M,N)$ is a division ring.

*Proof*: Let $f \in \text{Hom}_R(M,N)$. The kernel is a submodule of $M$, so it's either $0$ or $M$. Since $M$ is irreducible, either $f = 0$ or $f$ is an isomorphism. Thus $\text{Hom}_R(M,N)$ is a division ring.

**Theorem 108.3.2** (Jordan-Holder Theorem)
If $0 \to A \to B \to C \to 0$ is a short exact sequence of modules, then any composition series of $B$ has the same length and the same factors (up to isomorphism) as any other composition series of $B$.

*Proof*: This follows from the fact that any submodule of $B$ is a submodule of the composition series. The Jordan-Holder theorem is a generalization of the fundamental theorem of projective geometry.
