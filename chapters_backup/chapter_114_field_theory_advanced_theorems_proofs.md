# Chapter 114: Field Theory Advanced - Theorems and Proofs

## 114.1 Separable Extensions

### Theorem 114.1 (Primitive Element Theorem - Generalized)
Let $K/F$ be a finite extension. Then $K = F(\alpha_1, \dots, \alpha_n)$. If $K/F$ is separable, then $K = F(\alpha)$ for some $\alpha \in K$.

**Proof**: The separable primitive element theorem follows from the fact that the set of elements generating $K$ is dense in $K$.

### Theorem 114.2 (Kummer Theory)
Let $K/F$ be a cyclic Galois extension of degree $n$ containing the $n$-th roots of unity. Then $K/F = F(\sqrt[n]{a})$ for some $a \in F^\times$.

**Proof**: Using Kummer theory and the classification of cyclic extensions.

### Theorem 114.3 (Abhyankar's Inverse Problem)
Let $K/F$ be a finite separable extension. Then the degree $[K:F]$ equals the number of embeddings of $K$ into an algebraic closure of $F$.

**Proof**: Using the Galois correspondence and the fact that separable polynomials have simple roots.

## 114.2 Artin-Schreier Theory

### Theorem 114.3.1 (Artin-Schreier Theorem)
Every finite field extension $K/F$ is either $K = F$ or $K$ has degree $2$ over $F$.

**Proof**: Using the property that the only finite field extensions of $\mathbb{Q}$ are trivial or quadratic.

### Theorem 114.3.2 (Artin-Schreier Extension)
An extension $K/F$ is quadratic if and only if it is a Kummer extension or an Artin-Schreier extension.

**Proof**: Using the classification of quadratic extensions.

## 114.3 Galois Cohomology

### Theorem 114.4.1 (Hilbert's Theorem 90)
For a cyclic Galois extension $L/K$ with Galois group $G$, $H^1(G, L^\times) = 0$.

**Proof**: Using the norm residue symbol and the exact sequence $1 \to \mu_n \to \mathbb{G}_m \to \mathbb{G}_m \to 1$.

### Theorem 114.4.2 (Hilbert's Theorem 90 - Generalized)
Let $G$ be a finite group acting on an injective object $I$. Then $H^n(G, I) = 0$ for all $n \geq 1$.

**Proof**: Using the property that injective objects have trivial cohomology.
